# GPUIX App

[简体中文](README.zh-CN.md)

Generated by `gpuix create`. React describes the interface, standalone Hermes
runs JavaScript, and GPUI/wgpu renders directly to the native Android surface.
The main UI does not use WebView or React Native's view system.

## Development

```sh
bun install
bun run typecheck
bun run dev
```

## Android

```sh
bun run gpuix:doctor
bun run gpuix:build
bun run gpuix:run -- <ADB_SERIAL>
```

Release artifacts:

```sh
gpuix build --release
gpuix build --aab
```

`gpuix.android.json` owns the Android application ID, display name and version.
Increment `versionCode` for every store upload. The generated local release
uses a debug keystore; configure a real upload key before distribution.
