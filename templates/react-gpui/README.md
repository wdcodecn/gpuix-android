# GPUIX App

[简体中文](README.zh-CN.md)

Generated by `gpuix create`. React describes the interface, standalone Hermes
runs JavaScript, and GPUI/wgpu renders directly to the native Android or iOS
surface. The main UI does not use WebView or React Native's view system.

## Development

```sh
bun install
bun run typecheck
bun run dev
```

## Mobile (Android & iOS)

```sh
bun run gpuix:doctor
bun run gpuix:build             # Android debug APK
bun run gpuix:run -- <ADB_SERIAL>
bun run gpuix:build:ios         # iOS Simulator .app
bun run gpuix:run:ios           # Build, boot Simulator, install & launch
```

Release artifacts:

```sh
gpuix build android --release
gpuix build android --aab
gpuix build ios
```

`gpuix.config.json` owns the unified application ID, display name, semantic
`versionName` (e.g. `1.0.0`, `1.1.1`), `versionCode`, and optional `android` /
`ios` / `ota` sections. Increment `versionCode` for every store upload. Local
Android release builds use a debug keystore; configure a real upload key before
distribution.
